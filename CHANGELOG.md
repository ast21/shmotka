# Журнал изменений

Новые версии сверху. Одна задача — один PR — одна версия. Формат записи:

    ## X.Y.Z — ГГГГ-ММ-ДД — Короткое название
    #хэштег #ещё_хэштег
    - что изменилось, понятным языком

Версии: X — большие перемены, Y — новая возможность, Z — исправления. До первого релиза для людей — 0.x.y.
Каждая версия после мержа в `main` сама становится релизом на GitHub (тег `vX.Y.Z`).
