# Журнал изменений

Новые версии сверху. Одна задача — один PR — одна версия. Формат записи:

    ## X.Y.Z — ГГГГ-ММ-ДД — Короткое название
    #хэштег #ещё_хэштег
    - что изменилось, понятным языком

Версии: X — большие перемены, Y — новая возможность, Z — исправления. До первого релиза для людей — 0.x.y.
Каждая версия после мержа в `main` сама становится релизом на GitHub (тег `vX.Y.Z`).

## 0.2.0 — 2026-11-14 — Шпаргалка, витрина и Telegram
#шпаргалка #витрина #telegram #нейронки
- Витрина https://shmotka.pages.dev: все компоненты и готовые фрагменты в тёмной и светлой теме, переключатель акцента (в том числе свой цвет), просмотр «как на телефоне» и кнопка «скопировать код».
- Шпаргалка из 12 готовых фрагментов на классах daisyUI и Tailwind: страница с боковым меню, документ со скрываемыми оглавлением и панелью, счётчики, статусы и фильтры, прогресс, карта активности, переключатель вида, пустое состояние, уведомление, история версий, мобильный экран в духе Искры.
- Telegram Mini App: одна строка `connectTelegram()` — тема и цвет кнопки берутся из Telegram, шапка окна красится в цвет фона, смена темы в Telegram подхватывается сразу.
- Правила для нейронок (`docs/ai.md`): скопировать в CLAUDE.md проекта — и интерфейс собирается в стиле Шмотки.
- Обычная кнопка получила заметную рамку в светлой теме, активный пункт меню — мягкую подложку акцента вместо чёрной заливки.
- Цвет текста на акценте можно задать переменной `--shm-accent-fg`.

## 0.1.0 — 2026-11-14 — Токены и темы daisyUI
#старт #темы #daisyui #контраст
- Шмотка подключается в любой проект на Tailwind + daisyUI тремя строками CSS, установка — `npm i github:ast21/shmotka#v0.1.0`.
- Две темы: `shmotka-dark` (основа) и `shmotka-light`; без выбора тема следует настройке системы.
- Кнопки, бейджи, карточки, поля, чекбоксы, прогресс и остальные компоненты daisyUI выглядят в стиле системы.
- Цвет проекта: готовые акценты IdeaHub, Искры и Личных финансов (`data-accent`) или свой цвет одной переменной — мягкая подложка и цвет ссылок выводятся сами.
- Утилиты для того, чего нет в daisyUI: приглушённый текст, тонкие линии, мягкие подложки, цвета карты активности, шрифты Space Grotesk и JetBrains Mono.
- Все цвета хранятся в одном файле токенов; каждый PR проверяет контраст текста в обеих темах для каждого акцента.
